# 7. 문제 해결과 현재 한계

[← 이전: 콘솔과 로그](06-console-logs.md) · [목차](README.md)

막힌 기능의 영문 라벨을 먼저 확인하고 아래에서 같은 증상을 찾아보세요. 오류가 반복되면 [콘솔과 파일 로그](06-console-logs.md)의 메시지를 함께 확인합니다.

## 화면이나 입력이 기대와 다를 때

| 증상 | 확인할 순서 |
| --- | --- |
| 패널이 전부 사라졌어요. | `UI >`를 누릅니다. 일부 패널만 없으면 `Main >`, `< Features` 또는 상단 메뉴에서 다시 엽니다. |
| 카메라가 안 움직여요. | 콘솔을 닫고 텍스트·숫자 편집을 끝냅니다. 빈 뷰포트에서 왼쪽 드래그와 `W/A/S/D`를 시험합니다. 속도를 0까지 낮췄다면 `+`/`=`를 짧게 누릅니다. |
| 우클릭이나 휠로 시점을 못 바꿔요. | 현재 카메라 회전은 **왼쪽 드래그**입니다. 휠 카메라 줌은 연결되어 있지 않습니다. |
| 배치 단축키가 안 먹어요. | `Features → Placement Tool`을 열고 해당 탭을 선택합니다. 검색·숫자 입력과 콘솔을 끝내고 키를 다시 누릅니다. 버튼 조작도 가능합니다. |
| 기즈모를 바꾸다가 카메라가 움직였어요. | `Shift+W`의 `W`가 카메라 이동과 함께 처리될 수 있습니다. `Inspector` 위 도구 목록에서 `Move/Rotate/Scale`을 직접 선택합니다. |
| 물체를 선택했는데 목록에 없어요. | Placement 검색의 `Clear`를 누릅니다. 검색에 가려져도 Inspector 선택은 유지될 수 있습니다. |
| 가져온 모델이 기즈모 조작 후 뭉쳤어요. | 여러 메시의 그룹 변형이 상대 배치를 보존하지 못하는 현재 한계입니다. 한 메시씩 선택해 조작하세요. 자동 되돌리기는 없습니다. |
| `Delete`가 동작하지 않아요. | 숫자·텍스트 입력을 마치고 대상을 다시 선택합니다. Forward Delete 키가 없으면 `Delete Selected Object` 버튼을 사용합니다. |

## 불러오기에서 막혔을 때

| 증상 | 확인할 순서 |
| --- | --- |
| `Loadable Scenes`가 비었어요. | Scene Browser 검색을 지웁니다. `jEngine/`이 실행 작업 폴더인지, `Resource/` 아래에 `.scene`, `.gltf`, `.glb`가 있는지 확인합니다. 새 파일을 넣었다면 재실행합니다. |
| `Load Scene`이 회색이에요. | 목록에서 장면을 선택했는지 확인합니다. 현재 장면과 로더가 이미 같으면 버튼이 비활성화됩니다. |
| 파일을 눌렀는데 장면이 안 바뀌어요. | 파일 클릭은 선택만 합니다. `Load Scene`을 누른 뒤 `Active Scene`과 준비 상태를 봅니다. |
| 비동기라고 했는데 화면이 잠깐 멈춰요. | Model의 CPU 준비만 백그라운드입니다. GPU 업로드·장면 교체 단계는 동기식이라 멈춤이 남습니다. 반복해서 버튼을 누르기보다 완료·오류 상태를 확인합니다. |
| 취소가 즉시 끝나지 않아요. | 준비 단계 사이에서 확인하는 취소입니다. 진행 중인 디코더나 GPU 반영을 강제로 중단하지 않습니다. |
| Model 불러오기가 실패했어요. | `Import failed` 또는 `GPU finalization failed`의 내용과 파일·텍스처 경로를 확인합니다. 알려진 준비 실패에서는 기존 장면을 유지합니다. 기기 손실 등 모든 GPU 실패의 복구까지 보장하지는 않습니다. |
| PathTracing 실패 후 기존 장면도 사라졌어요. | 기존 동기식 로더는 교체 전 장면을 지울 수 있습니다. 엔진을 다시 실행하고 지원되는 Model 장면부터 확인하세요. |

## GI나 로그에서 막혔을 때

| 증상 | 확인할 순서 |
| --- | --- |
| SurfelGI를 켰는데 차이가 적어요. | `Enable SurfelGI`, 강도, 장면 완료 여부를 확인합니다. Inline 설정값만으로 GPU 지원을 판단하지 않습니다. 자세한 조건은 [SurfelGI](05-surfelgi.md)를 봅니다. |
| `Enable Inline Ray Gather` 버튼이 없어요. | 현재 간단한 패널에는 없습니다. 콘솔의 `r.surfelgi.inline_ray.enable`로 조회·변경합니다. |
| M4인데 Inline이 안 돼요. | 안정 MoltenVK에는 해당 실험 지원이 없습니다. 별도 실험 런타임 검증이 필요합니다. 환경변수 하나만으로 기능이 생기지 않습니다. |
| 실험 드라이버에서 문제가 생겨요. | 종료 후 `JENGINE_RUNTIME=stable ./scripts/run-macos.sh`로 기본 렌더링부터 확인합니다. |
| 콘솔 기록이 오래된 것부터 없어져요. | 최근 화면은 기본 1,024개까지만 보관합니다. 파일도 크기·개수가 제한된 회전 로그입니다. |
| `File drops` / `Sink errors`가 늘어요. | 대기열 초과 또는 파일 기록 오류입니다. 오류 상태 줄의 툴팁과 로그 위치·쓰기 권한·디스크 여유를 확인합니다. |
| 실행 직후 창이 닫혀요. | 실행 터미널의 메시지와 로그를 확인합니다. API 인수는 하나만 지정하고 리소스 작업 폴더, DXC·런타임 의존성을 [시작하기](01-getting-started.md)와 대조합니다. |

## 무엇을 저장하나요?

현재 일부 패널 표시·너비·활성 탭과 마지막으로 불러온 장면·로더 설정을 기억합니다. **추가한 물체, Inspector에서 바꾼 위치·회전·크기, 편집한 장면 전체를 저장하는 기능은 없습니다.** 마지막 장면을 다시 여는 것과 편집 내용을 복구하는 것은 다릅니다.

## 현재 제공하지 않는 편집 기능

| 기대할 수 있는 기능 | 현재 범위 |
| --- | --- |
| Undo / Redo | 지원하지 않음 |
| 일반 모델 복제·Clone | 지원하지 않음 |
| 작성한 장면 저장·내보내기 | 지원하지 않음 |
| 파일을 뷰포트로 끌어다 놓기 | 지원하지 않음 |
| 여러 임의 모델을 자산 브라우저에서 추가 배치 | 지원하지 않음. Scene Browser는 장면 교체 도구 |
| 전체 모델의 올바른 그룹 피벗 변형 | 상대 배치 보존에 제한이 있으므로 단일 메시 조작 권장 |
| GPU 업로드까지 완전히 끊김 없는 비동기 로딩 | CPU 준비만 비동기, GPU·장면 반영은 동기 |
| GPU 종류와 무관한 Inline GI | 지원 GPU·드라이버·장면 구조 필요 |

Windows와 macOS의 빌드·테스트 통과는 모든 Windows GPU에서 실제 렌더링을 검증했다는 뜻은 아닙니다. 화면 예시와 M4 측정값을 다른 장치의 결과로 일반화하지 마세요.

향후 작업과 우선순위는 [엔진 로드맵](../engine-roadmap.md), 이미 측정한 범위와 남은 병목은 [성능 보고서](../reports/editor-foundation-performance.md)에 정리되어 있습니다.
