# 7. 문제 해결과 지원 범위

[← 이전: 콘솔과 로그](06-console-logs.md) · [목차](README.md) · [다음: 저작 도구 →](08-authoring-tools.md)

오류가 나오면 먼저 화면의 메시지와 `Project tools → Console`, 파일 로그를 함께 확인하세요. 이 장은 기본 저작 화면과 클래식 화면을 구분합니다.

화면 위치를 잃었다면 [기본 화면의 ① 메뉴·⑤ Project tools](02-screen-camera.md), [프로젝트 설정의 ①~④](03-scene-browser.md), [저작 도구의 ①~⑤](08-authoring-tools.md) 그림에서 같은 영문 라벨을 찾으세요. 번호는 그림마다 새로 시작합니다.

## 화면·입력·저장

| 증상 | 확인할 순서 |
| --- | --- |
| Hierarchy나 Inspector가 없어요. | `F10`으로 저작 화면인지 확인하고 `Window → Reset layout`을 누릅니다. |
| Assets·Console이 안 보여요. | `Window → Assets / Console`을 켜고 아래 `Project tools`의 탭을 선택합니다. |
| 카메라가 안 움직여요. | 입력칸·콘솔·팝업을 끝내고 Scene에 초점을 둡니다. 기본 회전은 오른쪽 드래그입니다. 프로젝트에서 이동 키를 바꿨는지도 확인합니다. |
| 단축키가 안 먹어요. | 숫자·텍스트 편집을 끝내고 Hierarchy나 Scene을 클릭한 뒤 키를 떼었다 다시 누릅니다. 메뉴·버튼도 사용할 수 있습니다. |
| Q가 축 전환 대신 아래 이동해요. | 오른쪽 버튼을 누른 상태의 기본 Q는 카메라 하강입니다. 축 전환은 오른쪽 버튼을 놓고 누릅니다. |
| 선택한 물체를 못 찾겠어요. | Hierarchy 검색을 지우고 `F`를 누릅니다. 자신이나 부모의 Visible·Locked 상태도 확인합니다. |
| 그룹을 회전하다 오류가 나요. | 부모 비균일 배율 아래의 월드 회전은 로컬 전단이 필요할 수 있습니다. 균일 배율이나 Empty 그룹을 사용하고 오류 메시지를 확인합니다. |
| 저장·열기가 거부돼요. | Play를 Stop하고 편집 드래그를 마칩니다. 프로젝트 안의 올바른 `.jscene` 경로와 쓰기 권한을 확인합니다. |
| 종료나 새 장면에서 확인 창이 떠요. | `*`는 미저장 변경입니다. Save·Discard·Cancel의 의미를 확인하고 선택합니다. |
| Undo로 파일 이동이 안 돌아와요. | 장면의 Undo와 자산 파일 관리는 별도입니다. 휴지통 작업은 표시된 `.jeditor/trash/` 경로를 확인합니다. |

자동 복구는 [저장·복구 안내](03-scene-browser.md)를 보세요. `.bak`는 이전 정상 저장, `.jeditor/recovery.jscene`은 조건을 만족한 60초 주기 복구 파일입니다. Play 중 만든 임시 변경은 Stop으로 버리며, Undo 기록이나 현재 파티클 상태는 저장 파일에 포함되지 않습니다.

## 모델·텍스처·프로젝트

| 증상 | 확인할 순서 |
| --- | --- |
| Assets가 비었어요. | File에서 프로젝트를 열고 폴더·Search·Kind 필터를 지웁니다. Refresh와 카탈로그 상태를 확인합니다. |
| 모델을 추가했는데 아직 안 보여요. | Imports의 준비·업로드·오류를 확인합니다. 완료 후 Hierarchy에서 선택하고 F를 누릅니다. |
| Missing 또는 빈 텍스처가 나와요. | 원본뿐 아니라 glTF의 bin, 이미지, mtl 등 참조 파일을 같은 프로젝트 상대 경로에 준비합니다. Import file은 선택한 파일 하나를 복사합니다. |
| 가져오기 설정을 바꿨는데 모양이 달라요. | Geometry scale·Flip texture V·Generate missing normals와 저장된 메시별 변형을 확인합니다. 필요하면 원본 설정으로 되돌리고 Reimport합니다. |
| 재가져오기에서 메시 개수 오류가 나요. | 저장된 메시별 변형과 새 원본의 메시 구성이 다릅니다. 원본 구조를 유지하거나 새 모델 인스턴스로 추가해 변형을 다시 맞추세요. 메시 순서를 바꾼 경우도 결과를 확인합니다. |
| 카탈로그의 Prefab을 열 수 없어요. | `.jprefab`은 File → Instantiate prefab으로 배치합니다. `.jscene` 열기와 형식이 다릅니다. |
| 파일 이름·위치를 못 바꿔요. | 참조를 깨뜨리는 이동은 거부될 수 있습니다. 확장자를 유지하고 프로젝트 범위를 확인합니다. |
| 비동기인데 잠깐 멈춰요. | CPU 준비와 복사 제출 예산은 전체 프레임 시간 상한이 아닙니다. 드라이버 할당·가속 구조·셰이더·지형 재생성 비용은 남습니다. |
| 취소가 즉시 끝나지 않아요. | 디코더 호출은 협력 취소이며 이미 제출한 GPU 작업은 완료 뒤 회수됩니다. 모델 취소와 카탈로그 Cancel scan을 구분하세요. |

기존 PathTracing Scene Browser 경로는 동기식이며 실패 전 장면이 지워질 수 있습니다. 작성한 장면은 먼저 `.jscene`으로 저장하고, 일반 모델 인스턴스는 새 Assets 경로로 다루세요.

## GI·도구·패키지

| 증상 | 확인할 순서 |
| --- | --- |
| Inline GI 요청이 실제로 켜지지 않아요. | Project Settings의 지원 상태와 [M4 드라이버 조건](05-surfelgi.md)을 확인합니다. 안정 MoltenVK에 환경변수만 켜서 기능을 추가할 수는 없습니다. |
| 재질 그래프 연결이 거부돼요. | 상수 연산과 색 텍스처 하나의 곱셈 범위를 확인합니다. 텍스처 혼합·텍스처 Metallic/Roughness·순환 연결은 지원하지 않습니다. |
| 파티클이 RT 화면에서 안 보여요. | 현재 효과는 CPU 시뮬레이션·래스터 빌보드이며 RT/PathTracing 대상이 아닙니다. |
| Navigation이 레벨 전체를 만들지 않아요. | 현재 Bake는 선택한 Terrain의 로컬 메시에서 경로를 구합니다. 전체 레벨 수집·군중·에이전트 이동은 없습니다. |
| 플러그인 재로드가 실패해요. | 수동 CMake 빌드 완료, ABI 버전, 상태 크기·복원 함수를 확인합니다. 실패한 교체는 기존 정상 코드를 유지합니다. |
| 패키지를 다른 운영체제에서 실행할 수 없어요. | 현재 패키지는 만든 운영체제·아키텍처의 실행 파일과 의존성을 담습니다. 대상별 빌드가 필요합니다. |
| 패키지 만들기가 거부돼요. | 프로젝트·시작 .jscene·참조 자산과 런타임 도구를 확인하고 새 출력 폴더를 지정합니다. 누락된 의존성을 로그에서 찾습니다. |

## 현재 범위

저작 문서, 계층·그룹 변형, 모델 인스턴스, Undo/Redo·Prefab·저장/복구, 프로젝트 자산, 제한된 PBR 그래프, 로컬 변형 애니메이션, CPU 파티클·지형·선택 지형의 Recast 경로, 네이티브 에디터 확장과 런타임 패키지를 제공합니다.

실시간 공동 편집, 범용 게임플레이·물리·군중 시스템, 임의 셰이더 언어, GPU 파티클, 모든 작업의 프레임 시간 보장이나 모든 GPU의 Inline 지원을 뜻하지 않습니다. 정확한 구현·런타임 경계는 [기술 지원 표](../editor-authoring.md)에 정리합니다. 검증 범위와 수치는 최종 [성능 보고서](../reports/editor-foundation-performance.md)를 기준으로 확인하세요.
