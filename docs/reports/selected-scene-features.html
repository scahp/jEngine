실제 화면 6장

최종 네이티브 실행의 1280 × 720 GPU readback 원본입니다. 비교용 진단 머터리얼과 단순 형상으로 구성했으며, 화질을 평가하는 아트 장면은 아닙니다.

검증한 범위

  • 실제 실행: Khronos validation과 Metal API validation을 켠 상태에서 247프레임 · 88검사 통과. 기존 INI·사용자 설정과 실행 옵션을 보존했습니다.
  • 렌더러: Forward / Deferred의 SH, Forward POM, Deferred 매핑 6종, PPR 실제 투영과 동일 fallback 대조, 대기 산란을 확인했습니다.
  • Water: 0초 / 1.5초의 표면과 그림자·피킹을 확인했습니다. 물 뒤의 불투명 물체보다 가까운 물을 선택하며, 리드백 버퍼 오프셋 0 / 512에서도 같은 Water ID 216이 선택됐습니다.
  • 셰이더: 실제 엔진 생성 코드 112건 컴파일 통과 (DXIL 56 + SPIR-V 56). CPU / SPIR-V 레이아웃 계약 12건과 잘못된 ABI를 거부하는 대조 검사를 포함합니다.
  • CPU·문서·설정: 수학·베이크 71, 머터리얼 컴파일러 34, Water 문서 41, 프로젝트·베이커 35, 프로젝트 설정 70검사와 관련 회귀 검사가 통과했습니다. 잘못된 CLI 입력 5종도 초기화 전에 거부했습니다.

Windows 실기 검증은 남아 있습니다. 이번 배치는 macOS에서 수행했습니다. DXIL 컴파일은 Windows C++ 빌드나 실제 DX12 실행을 대신하지 않습니다.

적용 범위와 메모리

  • PPR: 단일 샘플 Deferred의 저장된 GBuffer와 설정한 평면 1개가 필요합니다. 화면에 없는 정보에는 환경 fallback을 씁니다.
  • 매핑·Water: Forward / Deferred용입니다. 충돌 형상·RT hit geometry는 갱신하지 않습니다. Water는 불투명 해석적 파형이며 유체 해석기가 아닙니다.
  • 대기: 지표면 단일 산란 근사입니다. 행성 규모 LUT 모델은 아닙니다.
  • 추가 메모리 (1280 × 720, 타깃 세트당): 다섯 번째 RG16F GBuffer 3.52 MiB는 중립값일 때도 필요합니다. 활성 패스의 RGBA16F 임시 이미지 2개는 14.06 MiB, PPR의 R32_UINT는 3.52 MiB입니다. 비활성 기능은 추가 compute / copy 패스를 건너뜁니다.
  • 비동기 준비: SH / Horizon 베이크 작업자 1개, 이미지 디코드 작업자 최대 2개. 유지 디코드 캐시는 64항목 / 128 MiB 한도이며 작업 임시 메모리는 별도입니다. GPU 업로드와 최초 파이프라인 생성은 소유 스레드에서 수행하므로 업로드 시간 상한을 보장하지 않습니다.
  • 측정 한계: 대형 에셋 공개 지연은 측정하지 않았습니다. Water 0초 / 1.5초는 모두 켜진 상태의 비교입니다. 매핑의 일부 음수 차이도 성능 향상 증거로 사용하지 않습니다.

병렬 확인: CSM은 기존에 있던 기능입니다

2019년에 구현됐고, 2022년 Vulkan 전환 때 기존 OpenGL 코드가 제거됐습니다. 따라서 남은 항목의 이름을 기존 CSM 복원·Vulkan / DX12 재통합으로 바로잡았습니다.

  • 3b7a12ba0c52 · 2019-07-27 · Added Cascade shadow. 이후 수정 이력도 jEngine main에 포함됩니다.
  • 797710bcf911 · 2022-08-25 · Remove all files to merge vulkan api. 이전 CSM 파이프라인과 GLSL 셰이더를 삭제했습니다.
  • 현재 활성 방향광은 ShadowVP 1개, 2D 그림자 레이어 1개를 사용합니다. 옛 CSM 팩토리·갱신 본문은 주석 상태입니다.
  • 현재 UI의 SurfelGI Cascade는 GI clipmap입니다. 방향광 CSM 설정과는 별개입니다. 이번 확인에서 CSM 구현은 추가하지 않았습니다.
